## 📖 Descripción

Repositorio con todos los trabajos, ejercicios y prácticas realizadas durante la cursada de **Programación I** en la **UTN Delta** durante el **1° Cuatrimestre de 2026**.

Aquí encontrarás desde ejercicios básicos de variables hasta estructuras de datos más complejas, todo implementado en **C++** y complementado con algoritmos en **PSeInt** para el aprendizaje inicial.
